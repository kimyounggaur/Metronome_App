# Pulse 메트로놈

한국어 레슨·개인 연습·공연용 메트로놈입니다. 기존 React 19 + TypeScript + Vite 8 + Tailwind + Web Audio/Worker 구조를 유지하고, 첨부 설계서의 필수 단계 00–10을 구현했습니다.

## 실행

검증 환경은 Windows, Node **24.14.0**, npm **11.9.0**입니다. Node 24 계열을 사용하세요.

```powershell
npm ci
npm run dev
```

개발 화면은 `http://127.0.0.1:5173`에서 열립니다. ZIP 원본 대신 이 README가 있는 소스 폴더에서 실행하세요.

```powershell
npm run build
npm run preview -- --port 4173
```

빌드는 타입 검사, Vite 번들, 버전별 서비스 워커 생성까지 수행합니다. 설치·오프라인은 production preview 또는 HTTPS에서 확인하세요. 배포 대상은 **dist 전체**이며 public/sw.js 템플릿만 복사하면 안 됩니다.

## 기본 조작

- 큰 BPM 숫자는 직접 입력할 수 있고, Enter 또는 다른 곳을 눌러 확정합니다. Escape는 편집 전 값으로 돌아갑니다. 빈칸·잘못된 입력은 마지막 유효 값으로 복귀하고 30–300 범위로 보정합니다.
- 숫자를 위아래로 드래그하거나 ±1/±5, 슬라이더, 4번 탭하기로 템포를 맞춥니다. 버튼을 길게 누르면 반복되고 창 포커스를 잃으면 멈춥니다.
- 일반 PC에서도 모든 조작을 사용할 수 있습니다. 상단 확대 아이콘은 공연 모드를 열며 ‘일반 화면으로’로 돌아옵니다. 모바일 가로 자동 전환은 설정에서 선택하며 기본은 꺼짐입니다.
- 키보드 Space는 재생/정지, T는 탭, 위/아래는 ±1, Shift+위/아래는 ±5입니다. 입력칸·버튼·열린 대화상자는 고유 키 동작을 유지합니다.
- 화면이 짧으면 스크롤할 수 있습니다. 확대를 제한하지 않으며 모달은 Escape, 닫기 버튼, 핸들 드래그로 닫을 수 있습니다.

## 음악 시간과 연습 규칙

BPM 기준은 4분음표·8분음표·점4분음표 중 선택합니다. 분자 셀 하나와 BPM 기준 음표를 분리합니다.

| 설정 | 한 셀 | 한 마디 |
|---|---:|---:|
| 4/4, 4분음표=120 | 0.5초 | 2초 |
| 6/8, 점4분음표=60 | 1/3초 | 2초 |
| 6/8, 8분음표=120 | 0.5초 | 3초 |
| 6/8, 4분음표=120 | 0.25초 | 1.5초 |

1/2/3/4분할은 박자표 분모의 셀을 같은 길이로 나눕니다. 6/8 기본 그룹은 3+3, 12/8은 3+3+3+3, 7/8은 2+2+3이며 사용자 그룹 합은 분자와 같아야 합니다. 그룹 변경은 기존 악센트를 보존합니다. ‘쉼’은 해당 셀의 모든 분할을 끕니다.

재생은 오디오·Worker 준비 성공 후 시작합니다. 정지는 대기 중인 시작과 미래 소리를 취소하고 출력에 8ms fade를 적용합니다. 수동 BPM은 다음 미예약 간격부터, 리듬·프리셋은 다음 본 연습 마디에서 한 묶음으로 적용합니다. 대기 중에는 적용 안내가 나타나며 박 표시에는 실제 재생 이벤트의 설정을 사용합니다. 볼륨·전역 뮤트는 즉시 부드럽게 반영합니다.

카운트인 뒤 첫 본 연습 시각부터 타이머를 셉니다. 카운트인·타이머 변경은 다음 재생부터, 갭·랜덤·속도 구성은 다음 본 연습 마디부터 적용합니다. 80→84, 2 BPM씩 2마디마다 훈련은 80 두 마디 → 82 두 마디 → 84 두 마디를 연주한 뒤 정지/유지/반복합니다. 감속도 같은 규칙입니다. 속도 훈련 중 큰 BPM과 슬라이더는 현재 재생 BPM을 보여 주며, 직접 조절하면 그 템포에서 수동 모드로 전환합니다. 저장된 훈련 설정을 매 박 덮어쓰지 않습니다.

갭 3:1은 본 연습 3마디 소리/1마디 묵음을 반복합니다. 랜덤 묵음은 박 또는 마디마다 한 번 정해 모든 자식 분할에 적용합니다. ‘시각·햅틱 유지’를 끄면 훈련 묵음 중 박·플래시·햅틱 단서를 숨깁니다. 전역 뮤트는 시각 메트로놈을 유지합니다. 플래시는 기본 꺼짐, 최대 초당 2회이며 reduced-motion에서는 끕니다.

## 프리셋·셋리스트·백업

프리셋 새로 저장, 현재 항목 업데이트, 이름 변경, 복제, 검색과 삭제를 지원합니다. 현재 항목과 저장본이 다르면 ‘변경됨’이 표시됩니다. 여러 셋리스트에서 같은 곡을 반복 배치하고, 항목 선택·추가·삭제·위아래 이동을 할 수 있습니다. 모바일과 공연 화면은 같은 ID/항목 위치를 사용하며 마지막 곡 다음은 첫 곡입니다.

저장 형식은 `pulse:data:v2` 하나에 schemaVersion, settings, presets, setlists, navigation을 넣습니다. 설정은 180ms 동안 합쳐 쓰고 입력 확정·포인터 해제·정지·페이지 종료 때 즉시 쓰기를 시도합니다. 프리셋·목록·가져오기는 한 번에 저장합니다. 실패하면 메모리 상태와 백업을 유지하고 오류를 표시합니다.

기존 v1 세 키는 **삭제하지 않습니다**. 전체 검증 후 복사본을 이관합니다. 기존 /4는 4분음표, /8은 8분음표 기준으로 바꿔 실제 속도를 보존하고 분 단위 타이머는 초로 변환합니다. /16은 속도 보존 단위를 임의로 정하지 않고 오류로 안내합니다. 반복 셋리스트 항목은 각각 고유 ID를 받습니다.

손상·미래 버전 데이터를 만나면 원본을 덮어쓰지 않고 기본 메트로놈을 엽니다. ‘원본 데이터 내려받기’로 보관한 뒤 저장 패널에서 정상 백업을 검증·복원하세요. 명시적 복원 시 원본은 `pulse:recovery:v2`에도 보존합니다. 복사 실패 시 파일 다운로드나 수동 복사를 사용할 수 있습니다. 가져오기는 전체 검증과 미리보기 후 반영하며 기본은 병합입니다. 교체는 체크박스로 대체 범위를 확인한 뒤 적용합니다.

제품 한도: BPM 30–300 정수, 볼륨 0–1, 속도 변화 1–30, 마디 간격·갭 1–64, 타이머 1–3600초, 이름 1–80자, 파일 2MiB, 프리셋 1000개, 셋리스트 100개, 목록당 항목 1000개.

## PWA·기기 복구

‘오프라인 사용 준비 완료’는 첫 재생 전 JS/CSS/Worker/아이콘 캐시와 활성화를 확인한 뒤 표시합니다. 새 버전은 준비 후 대기하며 자동으로 연습을 중단하지 않습니다. ‘업데이트 적용’ 또는 ‘정지 후 업데이트 적용’을 누르면 저장 성공을 확인한 뒤 갱신합니다. 저장 실패 시 새로고침을 보류합니다. 다른 앱의 캐시와 서비스 워커는 유지합니다.

설치 prompt가 있는 브라우저에는 설치 버튼을, iOS에는 공유→홈 화면 추가 안내를 제공합니다. 설치된 standalone 화면에서는 숨기고 닫기 선택은 저장합니다. Wake Lock은 보이는 화면에서 재생할 때만 요청하며 복귀·해제 이벤트를 처리합니다.

메인 스레드/오디오 시계의 예약 중단이 0.5초를 초과하거나 AudioContext가 중단되면 ‘중단됨’으로 전환합니다. 재개는 새 연습으로 시작하므로 카운트인·타이머도 다시 시작합니다. 과거 클릭을 한꺼번에 재생하지 않습니다. 웹앱은 OS 절전, iOS 정책, Bluetooth 지연을 보장하지 않습니다. 실제 iPhone/Android 설치·화면 잠금·출력 검증 절차는 [PWA 문서](docs/PWA.md)에 있습니다.

100ms 예약 창을 넘기는 짧은 지연에서는 이미 지난 클릭을 건너뛰고 미래 박을 이어갑니다. 자동화로 키 30개를 대기 없이 몰아 넣은 스트레스 검사에서 이 정책이 관찰됐으며, 일반 입력 간격과 장시간 실행 결과는 [검증 보고서](docs/VALIDATION.md)에 별도로 기록했습니다.

## 검증

```powershell
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run test:pwa
```

E2E는 독립 Chromium context와 테스트용 localStorage를 사용합니다. PWA는 별도 4173 origin에서 production A/B 두 버전, HTTP 캐시 비활성화, 서버 연결 차단을 검증하고 서버를 종료합니다. 사용자 브라우저의 프리셋은 건드리지 않습니다. Safari/Android 실기와 물리 음향 측정은 Chromium 자동 검사와 구분합니다.

[최종 검증 보고서](docs/VALIDATION.md), [기준선](docs/BASELINE.md), [오디오 계약](docs/AUDIO-PLAN.md), [PWA 증거](docs/PWA.md)를 확인하세요. 계측 스크립트는 scripts/measure.mjs와 scripts/measure-storage.mjs에 있습니다. 개발 빌드의 window.__pulseDiagnostics는 로컬 관찰용이며 production 기본 UI에는 노출하지 않습니다.

원본 복귀는 상위 폴더의 수정하지 않은 `메트로놈 웹앱.zip`을 **새 폴더**에 풀어 수행할 수 있습니다. v2 백업은 먼저 내려받으세요. 이전 앱은 v2를 읽지 않으므로 기존 v1 키를 보존한 상태에서 별도 origin으로 비교하는 것이 안전합니다. 선택 단계 11(연습 기록·루틴), 외부 배포·서비스 연결은 이번 범위에 포함하지 않았습니다.
